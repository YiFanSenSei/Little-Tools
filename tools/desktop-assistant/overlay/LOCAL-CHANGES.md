# 截图收纳改进说明

## 0.6.1 悬停误触修复

移除鼠标在头顶移动时自动触发摸摸的逻辑。现在悬停仅显示快捷按钮，不触发互动、音效、爱心特效或亲密度变化；单击才摸摸，双击开面板，按住移动仍是拖动。增加了连续 100 次无按键移动的交互回归检查。

## 0.6 真正的角色动画与基础形象

默认形象升级为鲸鱼娘「深深」，10 段 640×360、24 fps 透明 WebM 原始动作按互动切换。每次摸摸交替挥手和挠痒回应；拖动使用被提起的动画；喂食播放吃饭、玩耍播放宅舞；还有睡觉、叫醒、伸懒腰和开心。动作完整播放结束后回到待机，不再被两秒的特效计时器截断。睡觉与拖拽动画按状态持续播放。

右键 → 宠物设置 → 基础形象卡片，新增小狐狸、小黄鸭、小螃蟹（像素 GIF），并保留经典静态头像。选择动态形象会开启角色动画；关闭「播放角色动画」则显示静态预览。自定义上传功能保留。内置形象选择、尺寸、动作开关会随设置保存；旧默认头像在首次启动新版时迁移为动态鲸鱼娘，原有自定义图片不替换。

动画、静态预览均已打包，运行时不访问 GitHub。只播放当前桌宠，选择卡片使用静态预览；隐藏窗口时暂停视频。默认全身角色尺寸 160 px，可调 64–240 px。角色使用透明背景，按人物在视频中的区域布局，避免宽视频把全身缩成小点。

新增素材核对与角色状态测试，隐藏窗口交互检查会验证视频像素帧发生变化、播放进度前进、喂食动作不会在两秒被截断、动作结束回待机，以及全部五种形象的切换。`scripts/fetch-pet-assets.ps1` 可按清单重新下载并校验来源文件，不把系统代理配置写入源码。

鲸鱼娘形象与动画按上游 CC BY-NC-SA 4.0 用于个人非商业版本。各素材作者、来源和许可随应用打包，详见 THIRD-PARTY-NOTICES.md；公开目录采用构建配方方式；完整组装应用仅供本机使用。

## 0.5 桌宠互动

单击鲸鱼娘摸摸，连续双击打开助手面板；悬停后底部有喂食、玩耍和直接开面板的小按钮。鼠标悬停只显示快捷按钮，单击才触发摸摸。拖动有提起与倾斜反馈，松手落地回弹；拖动不会误判为单击或双击。

面板和右键菜单均支持摸摸、喂小鱼干、一起玩、睡觉和叫醒。不同动作有相应的气泡和程序动画。亲密度、活力和睡眠状态保存在本机 `pet-config.json`，重启保留；互动设有冷却，避免重复输入堆积。玩耍消耗活力，喂食补充活力。睡觉不暂停截图收集，点睡着的桌宠会叫醒它。

自主动作每 30 秒判断一次：伸懒腰，长时间未互动时短暂打盹；不会移动窗口。可在设置关闭「自主小动作」或「轻柔动画」。拖动、隐藏或展开面板时不触发自主动作。只处理桌宠窗口里的鼠标事件，没有全局键盘记录、屏幕识别或联网聊天。

保留默认鲸鱼娘和自定义形象。动作通过现有图像的平移、旋转、缩放和特效呈现，并非新绘制的逐帧角色动画。GIF 自身动画仍沿用原图。

设计参考（未引入其程序或角色素材）：
- https://github.com/LorisYounger/VPet ：桌宠状态与互动入口。
- https://github.com/LGaben/Desktop-Pets ：待机与交互状态切换。

更新桌面快捷方式：打包后运行 `scripts/start.ps1 -CreateShortcutOnly -UpdateDesktopShortcut`。沿用鲸鱼娘图标，快捷方式会指向当前打包版本。

基于 https://github.com/wonderSiesta/desktop-assistant 的现有 Electron + React 项目增量修改，保留日程、笔记、系统工具、托盘和主题。

新增独立「截图收纳」页作为默认入口：Win+Shift+S 截图后收集新的剪贴板图片；原图单独存 PNG，索引保存缩略图；支持多选导出、复制原图、预览、重命名、收藏、搜索、分页及可恢复回收站。

## 使用

优先双击 `build-output/pet-0.6.1/win-unpacked/桌面助手.exe`，或项目根目录 `启动.cmd`。已打包版本不需要安装 Node.js。

开发模式：`npm ci` 后运行 `npm run dev`；构建使用 `npm run build`，数据测试使用 `npm test`，生成免安装目录使用 `npm run pack`。

应用运行后继续用 Win+Shift+S。关闭完整主窗口会收回鲸鱼并继续收集；真正退出请用右键或托盘「退出」。重开后历史仍在。不要只复制单个 EXE：免安装程序需要完整 `win-unpacked` 文件夹。升级前先从旧版托盘退出，以免旧版单实例锁拦截新版启动。

图片剪贴板不提供可靠的来源区分，所以也会收集其他程序复制的新图片。连续相同内容只收集一次；启动前或暂停期间的图片不自动补入，可点击「导入当前图片」。Windows 使用轻量变更序号检查（100 ms），仅在有变化时读取图片（350 ms）；原生检测不可用时自动降级为约 1.4 秒检查，极短时间内被覆盖的剪贴板内容不能保证恢复，常规人工连续截图适用。

文字自动记录默认关闭，沿用原有文字剪贴板工具，可在截图页自行启用。操作系统自身的云剪贴板功能独立于本应用，本应用不上传、不联网分析截图。

## 本机数据与隔离

数据默认放在当前用户应用数据的 `LittleTools/DesktopCapture` 下，与原版 desktop-assistant 和 GitHub Radar 分开。可设置环境变量 `CAPTURE_DATA_DIR` 显式指定本机目录。应用仅运行一个实例；开发服务器使用 3220，不占拾星的 3210。

原图在 `captures/images/`，索引与备份在 `captures/index.json`、`captures/index.backup.json`。自动保存串行、原子替换；异常显示错误并暂停收集，不会静默回退为仅保存文字。可在界面打开数据目录。

容量上限 2 GB，包含回收站；不会自动丢弃旧截图。先导出，再移入回收站，确认后清空可回收空间。永久清空需二次确认；回收站不是操作系统回收站。备份索引主要用于上次写入失败恢复，不能代替完整数据备份。

## 0.4 小鲸鱼宠物

- 默认启动只有透明置顶小鲸鱼，不显示任务栏主窗口；点击展开最近 6 张截图，可复制原图或进入完整截图库预览。关闭面板不退出程序。
- 按住左键拖动，移动超过 6 DIP 才算拖动；松开靠边吸附并保存显示器内的相对位置。显示器断开、分辨率或 DPI 变化时重新约束到可见工作区。
- 新图真正保存成功后才出现短暂开心动画和气泡；气泡只显示数量，不展示新图。暂停时鲸鱼闭眼休息，保存失败时显示感叹号和原因入口。查看完整截图页后清除未读角标。
- 右键可截图、开库、看收藏、暂停/继续、进设置、临时隐藏 10 分钟和退出。托盘「找回小鲸鱼」可随时找回临时隐藏的窗口。
- 设置支持 64–144 px 尺寸、动画、系统提示音、登录后自启。收图提示音和自启默认关闭；自启仅在打包版中可开启。开启后不要移动免安装目录，否则要重新设置自启。
- 从助手「截一张」发起时先隐藏主窗口和悬浮层，再打开 Windows 截图。新图收到后恢复鲸鱼；取消或没有新图时 30 秒后恢复。系统 Win+Shift+S 不被拦截，如需截全屏可先临时隐藏鲸鱼。
- 宠物设置独立保存在同一用户数据目录的 `pet-config.json`，截图库格式保持不变。没有读取其他软件会话、API 余额或私人密钥。
- 默认形象按用户要求使用参考项目 DSniang1.png 鲸鱼娘，保留原 PNG；没有引入 DSH 依赖，也没有把该素材声明为 MIT。详见 THIRD-PARTY-NOTICES.md。参考：https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget 。
- 透明边缘使用 Electron 鼠标穿透；前台为管理员权限窗口时，Windows 可能限制低权限进程的悬停消息，可先切到普通窗口或使用托盘入口。独占全屏应用可能覆盖置顶宠物。

## 0.4.1 名称与自定义形象

界面名称统一为「桌面助手」，快捷面板的完整入口改为「打开桌面助手」。默认显示参考项目的原版鲸鱼娘。

更换形象：右键形象 → 宠物设置 → 上传自己的形象。支持 PNG、JPG、GIF、WebP，最大 10 MB，宽高各不超过 4096 像素；建议透明 PNG 或 GIF。上传后立即切换，重启仍保留；点击「恢复默认」回到原版鲸鱼娘。取消文件选择不会改变形象。

图片保存在本机用户数据的 `pet-skins/` 中，文件名使用内容摘要，不保留原始文件名。不会上传，不加入源码或安装包。GIF 原始动画保留；轻柔动画开关控制助手附加的浮动与收图动作。

## 0.4.2 收集性能与点击互动

修复开启收集后拖动周期卡顿：旧版每 350 ms 都会读取完整剪贴板图片、编码 PNG 并计算摘要。现在由隐藏的 Windows PowerShell 辅助进程查询系统剪贴板变更序号，只把序号传回主进程；剪贴板不变时不读取、编码图片。辅助进程异常会自动重试，暂时使用较低频率的兼容检查；退出助手会结束辅助进程，助手异常退出后辅助进程也会自行结束。

按住宠物时暂缓读取图片，松手后恢复检查，不重设剪贴板基线，也不改变收集开关。拖动期间如有多次剪贴板覆盖，只能收集松手后仍保留的最后一张图。保存未完成时不重复读取；剪贴板暂时被占用时会重试。鼠标不移动时不重复设置窗口位置；单击不写入位置配置；宠物状态不再复制整个缩略图库。

参考鲸鱼组件的弹性按压交互，新增按压形变、松手回弹、短暂星光和爱心，以及本地合成的两声轻音。只有单击会触发互动并展开面板，拖动、取消拖动不会触发点击。宠物设置新增「点击互动音效」，默认开启，与默认关闭的「收图提示音」分开；关闭「轻柔动画」时停用回弹和特效。音效不读取麦克风，不下载音频。

回归检查：`npm test`；构建后运行 `npx --no-install electron scripts/check-pet-interaction.cjs` 检查隐藏测试窗口中的点击、拖动、静音和动画开关，音频测试输出静音；`npx --no-install electron scripts/check-capture-performance.cjs` 用合成 4K 图比较重复检查开销。两者均不读取真实剪贴板或用户截图库。此机合成 4K 图 40 次未变化检查：旧读取方式约 6.5 秒、单次最长约 178 ms；新方式不再读取或编码图片。该数据衡量重复检查开销，不代表每张新截图保存耗时。
