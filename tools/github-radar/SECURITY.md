# 安全与隐私

本项目为个人本地应用，只监听 127.0.0.1，不支持公网多用户部署。

默认只向 github.com 和 api.github.com 发送获取公开榜单、仓库元数据的请求。没有遥测、分析服务或第三方 AI 调用。你的兴趣词在本地用于匹配，不随请求发送给 GitHub。配置代理后，网络请求会通过你选择的代理。点击外部项目链接会打开 GitHub 网站。

可选 `GITHUB_TOKEN` 仅作为 GitHub API 请求头发送给 api.github.com，不返回网页，不主动写入报告。`.env` 是本地明文配置，应限制其他用户访问。操作系统、代理服务和自行开启的调试工具仍可能记录网络活动。

`data/` 可能包含兴趣偏好、使用时间、任务信息、错误堆栈和本机路径；不要发布。公开截图也应检查这些内容。

不要在公开 Issue 中粘贴 token、完整日志或个人路径。报告漏洞时只提供脱敏后的最小复现。维护者设置私人安全报告渠道后优先使用该渠道；当前仓库尚未声明私密联系方式。

`npm run privacy:check` 是辅助扫描，只识别部分常见敏感信息模式，不保证发现所有个人信息。发布前仍须人工检查。

1.0.2 会只读获取 Windows 当前用户启用的系统 HTTP 代理，并让 GitHub 请求使用它；显式代理环境变量优先。该配置不写入报告或发布文件。网络诊断只输出路由类型、固定 GitHub 域名与错误代码。代理凭据通过子进程环境、GitHub 请求头通过标准输入传递，不放在命令行参数或正常日志中；本机同账户管理员或调试工具仍可能读取进程信息。TLS 始终验证，跨域重定向被拒绝。
