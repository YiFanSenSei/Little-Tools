每周自动扫描

网页关闭后，由 Windows 任务计划程序执行。电脑关机或未登录期间不能运行；错过的任务会在电脑启动且用户登录后补跑。打开本应用时也会检查是否需要补跑。

安装任务：双击项目中的「安装每周任务.cmd」。暂停后，已安装任务会读取此开关并跳过扫描。

推荐是怎么来的？

直接读取 GitHub Trending，使用公开描述和主题进行规则分类，结合新增 Star、累计 Star、增长比例和你的兴趣排序。最高 100 分，仅供发现参考；没有调用付费 AI，也没有运行或审计这些项目。每次最多补充前 12 个仓库的许可证和维护信息。

数据保存在项目 data 目录。网络错误不会覆盖上次成功结果。
